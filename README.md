# 🇧🇬 Bulgarian Macro Dashboard

Автоматизиран интерактивен дашборд за макроикономическото състояние на България.

**Данни от:** НСИ и БНБ (чрез Eurostat API) · **Обновяване:** Всяка неделя

## Индикатори

| Серия | Описание | Честота | Източник |
|-------|----------|---------|----------|
| BG_GDP_YOY | БВП — реален растеж г/г | Тримесечно | Eurostat (НСИ) |
| BG_INDPRO | Промишлено производство | Месечно | Eurostat (НСИ) |
| BG_CONS | Потребление на домакинствата | Тримесечно | Eurostat (НСИ) |
| BG_ESI | Икономическо доверие (ESI) | Месечно | Eurostat |
| BG_HICP | Инфлация (ХИПЦ) | Месечно | Eurostat (НСИ) |
| BG_HICP_CORE | Базисна инфлация | Месечно | Eurostat (НСИ) |
| BG_UNRATE | Безработица | Месечно | Eurostat (НСИ) |
| BG_WAGES | Растеж на компенсацията, г/г | Тримесечно | Eurostat (НСИ) |
| BG_CA_GDP | Текуща сметка (% от БВП, 4-тримесечна плъзгаща) | Тримесечно | Eurostat (БНБ) |
| BG_LT_RATE | Дългосрочен лихвен процент | Месечно | Eurostat (БНБ) |

## Composite Macro Score

Скорът (0–100) отразява текущото макроикономическо положение спрямо историческото разпределение от 2000г.

| Режим | Диапазон | Описание |
|-------|----------|----------|
| ЕКСПАНЗИОНЕН | 80–100 | Силен растеж, ниска инфлация, нисък риск |
| ЗДРАВ | 65–80 | Добри условия, умерен растеж |
| СМЕСЕН | 50–65 | Смесени сигнали |
| ВЛОШАВАЩ СЕ | 35–50 | Нарастващи рискове |
| РЕЦЕСИОНЕН | 0–35 | Свиване, висока инфлация или безработица |

## Структура

```
bg-macro-dashboard/
├── catalog/          # Дефиниции на сериите и полярности
├── sources/          # Адаптери за Eurostat API
├── core/             # Математически примитиви и scorer
├── export/           # HTML генератор
├── data/             # Кеш на данните (JSON)
├── output/           # Генериран HTML дашборд
├── .github/workflows # GitHub Actions за автоматизация
└── run.py            # Главен скрипт
```

---

## Локално стартиране

```bash
pip install -r requirements.txt

# Обновяване на данните и генериране на дашборд
python run.py --briefing --refresh

# Само статус
python run.py --status
```

## Автоматизация

GitHub Actions workflow се изпълнява всяка неделя в 09:00 Sofia time.
Може да се стартира ръчно от Actions таба с опция за форсирано обновяване.
